Slash командите се пишат; тези неща се натискат. Те са разликата между „работя с Claude Code" и
„работя с Claude Code бързо".

## Клавишни комбинации

| Комбинация | Какво прави |
| --- | --- |
| `Shift+Tab` | Превключва **permission mode** — циклично между режимите на разрешения. Основният начин да влезеш в plan mode. |
| `Esc` | Прекъсва Claude по средата на работа. Спира текущото действие, без да губиш сесията. |
| `Esc` `Esc` | Двойно натискане: връща те назад в разговора, за да редактираш предишно съобщение и да тръгнеш в друга посока. |
| `Ctrl+O` | Разгъва съкратения output — показва пълните детайли на изпълнените инструменти. |
| `Ctrl+R` | Търсене в историята на предишните ти промптове. |
| `Ctrl+C` | Прекъсва текущия вход. Двукратно — излиза от Claude Code. |
| `Ctrl+D` | Излиза от сесията. |
| `↑` / `↓` | Разлистване на предишни промптове. |

### Permission modes

`Shift+Tab` минава през режимите на разрешения. Това са реалните им имена, същите, които виждаш и в
`settings.json`:

| Режим | Поведение |
| --- | --- |
| `default` | Пита за разрешение при всяко действие, което променя нещо. |
| `acceptEdits` | Приема редакциите на файлове автоматично, но пита за останалото. |
| `plan` | **Plan mode** — Claude само чете и мисли, не променя нищо. Първо получаваш план. |
| `bypassPermissions` | Не пита за нищо. Внимавай къде го използваш. |

:::warning[Plan mode е най-подценяваният режим]
За всяка промяна, която ще пипне повече от два-три файла, започни в plan mode. Прочиташ плана,
поправяш го с една реплика и чак тогава пускаш изпълнението. Спестява много повече време, отколкото
отнема.
:::

### Двойното Esc

Най-полезният трик, който хората не знаят. Когато Claude тръгне в грешна посока, натискаш `Esc`
два пъти, връщаш се на съобщението, което е задало грешния курс, преформулираш го и продължаваш
оттам.

Разликата с `/clear` е, че не губиш всичко преди този момент — само отрязваш грешния клон.

## Префикси в промпта

| Префикс | Какво прави | Пример |
| --- | --- | --- |
| `!` | Изпълнява shell команда директно, без да минава през модела. Резултатът остава в контекста. | `!git status` |
| `#` | Записва бележка в паметта (`CLAUDE.md`). Питат те в кой memory файл да отиде. | `# винаги използвай pnpm, не npm` |
| `@` | Споменава файл или директория — съдържанието влиза в контекста. Има автодовършване. | `@src/api/client.ts` |
| `/` | Slash команда. | `/compact` |

<Steps>
  <Step title="`!` за бърза проверка">
    `!git diff --stat` е по-бързо и по-евтино от „покажи ми какво съм променил" — няма кръг към
    модела.
  </Step>
  <Step title="`#` за правила, които повтаряш">
    Хванеш ли се, че обясняваш едно и също за втори път, запиши го с `#`. Следващата сесия вече го
    знае.
  </Step>
  <Step title="`@` вместо описание">
    `@convex/schema.ts` е по-точно от „виж файла със схемата" и спестява едно търсене.
  </Step>
</Steps>
