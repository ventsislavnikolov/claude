## If you only have two minutes

These four things change how you work with Claude Code more than anything else:

<Steps>
  <Step title="Write a CLAUDE.md">
    Run `/init` in your project. The file is read at the start of every session and saves you
    endless re-explaining — details in [Tips](/workflow/tips).
  </Step>
  <Step title="Plan before you write">
    Press `Shift+Tab` to reach **plan mode** for larger changes. Claude proposes a plan first, then
    touches the code.
  </Step>
  <Step title="Keep the context clean">
    `/clear` between unrelated tasks, `/compact` once a session gets long.
  </Step>
  <Step title="Delegate the big jobs">
    Subagents (`/agents`) and skills keep your main context small and focused.
  </Step>
</Steps>
